# 对话追问段 — 下一步行动建议

> 本文件用于生成对话追问段，不写入报告。在 Step 3 数据收集阶段已加载，报告写入完成后在对话中输出追问段。

## 输出格式

```
基于以上分析，您可能感兴趣的下一步：

1. **[动作标题]**
   [一句话说明为什么推荐，引用报告中的具体数据]
   > 💬 您可以直接说："[快捷指令]"

2. **[动作标题]**
   ...

3. **[动作标题]**
   ...
```

## 选择规则

1. **发品保底**：报告中含 1688 或 Amazon URL 时，"发品到国际站"**必须**作为第 1 条建议；其余 1-2 条按以下规则由你自选。无此类 URL 时不强制。
2. **数据驱动**：每条建议必须引用报告中的具体数据（产品名、排名、URL、痛点关键词等）。没有数据支撑则不推荐。
3. **路径约束**：只推荐当前路径"适用路径"列包含的动作。
4. **不重复维度**：3 条建议覆盖不同动作类型。
5. **不推荐自己**：不要建议"再查一次热品"。
6. **快捷指令口语化**：用户可以直接复制说出来的自然语言。
7. **不硬凑**：如果当前路径可选动作不足 3 条，输出 2 条即可。

## 动作目录

| 动作 | 适用路径 | 触发信号 | 快捷指令示例 |
|------|---------|----------|-------------|
| 发品到国际站 | 2B(Amazon), 2C-1688 | 报告中有 Amazon URL 或 1688 URL | "帮我把第 X 个商品发到国际站" |
| 在 1688 找同款货源 | 2B, 2C(非1688), 2D | 有站外高销量产品 | "帮我在 1688 找第 X 个商品的同款" |
| 竞品深度拆解 | 仅 2B(Amazon) | 报告中有具体 ASIN | "帮我深入分析第 X 个产品的竞争情况" |
| 蓝海细分发现 | 全部路径 | Section 5 判定同质化严重或竞争红海 | "帮我找 {品类} 里的蓝海细分市场" |
| 差异化选品 | 2C 优先，其他路径有明确痛点时可用 | Section 4 中有具体痛点描述 | "帮我找带 {功能/特性} 的差异化产品" |

> - 路径判定依据 Step 1 的平台判定结果（2A=国际站, 2B=Amazon, 2C=Temu/SHEIN/1688/Shopee/TikTok, 2D=eBay/AliExpress/Lazada）
> - 2A（国际站）路径：商品已在国际站，"发品"和"找同款"均无意义；优先推荐蓝海细分、差异化选品
> - 非 Amazon/1688 平台（Temu/SHEIN/Shopee/TikTok/eBay/AliExpress 等）的商品链接不具备 URL 发品能力，追问中不提供"发品到国际站"指令；仅 Amazon 和 1688 商品链接可触发"发品到国际站"建议

#### A. URL 发品白名单（核心约束）

目前生意助手**只具备 Amazon 和 1688 链接的 URL 发品能力**。其他平台链接**不得**触发 URL 发品追问，避免空头承诺。

| 链接来源 | URL 发品支持 | 在追问段中的处理 |
|---------|------------|----------------|
| Amazon（amazon.com / amazon.*） | ✅ 支持 | 触发 URL 发品追问 |
| 1688（detail.1688.com / 1688.com / m.1688.com） | ✅ 支持 | 触发 URL 发品追问 |
| 阿里巴巴国际站（alibaba.com） | ❌ 不支持 | **禁止**触发 URL 发品追问 |
| Temu / SHEIN / Shopee / TikTok Shop / eBay / AliExpress / Lazada | ❌ 不支持 | **禁止**触发 URL 发品追问 |

> ⚠️ 判定"发品保底"规则时，必须先按此白名单校验链接域名。alibaba.com 域名下的商品链接不属于 URL 发品候选，即使报告中包含 alibaba.com 链接也不得触发发品追问。
