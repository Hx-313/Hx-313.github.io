# Data Source Badges

| Badge | When to Use |
|-------|-------------|
| Alibaba.com | 国际站 MCP 数据（`data_advisor_*`）或 `product_supplier_search` 数据 |
| Amazon | Jungle Scout 数据（`js_product_database_query`） |
| Temu | `global_hot_selling_products` 热销数据 |
| SHEIN | `global_hot_selling_products` 热销数据 |
| 1688 | `global_hot_selling_products` 热销数据 |
| Shopee | `global_hot_selling_products` 热销数据 |
| TikTok | `global_hot_selling_products` 热销数据 |
| eBay / AliExpress / Lazada | `web_search` 搜索数据 |

## Rules

1. 来源列按实际数据平台标注
2. 不要暴露内部工具名（报告中写平台名，不写工具名）
