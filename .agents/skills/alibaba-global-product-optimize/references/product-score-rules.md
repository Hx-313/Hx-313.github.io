# 商品质量分评分规则

## 质量分结构

商品质量分范围为 **0–6 分**，由两部分组成：

- **基础分（0–5 分）**：评估商品信息完整性、规范性与基础质量
- **加分项（0–1 分）**：评估商品竞争力，受国家/地区与商品类型影响

**公式：** `最终质量分 = 基础分（最高 5 分）+ 加分项（最高 1 分）`

## 评分规则概览

### 基础分（满分 5 分）

基础分默认从 **5.0 分** 开始，按检测到的问题进行扣减。

**主要扣分维度：**
- **商品主图**：图片质量问题（每项 -0.1，最高 -0.3）、图片数量不足（-0.2）、尺寸/比例问题
- **商品标题**：重复词、错误词、缺少核心词
- **商品属性**：属性不完整（<80%）、标题与属性不一致（-0.1）
- **发品类目**：类目错误或类目不匹配
- **交易信息**：假价格（-0.3）、每产品规格的可售数量需大于等于最小起订量（-0.1）、规格文本表达问题（-0.1）
- **商品详情**：详情质量不足或缺少关键信息

### 加分项（满分 1 分）

加分项会根据 **国家/地区** 和 **商品类型**（交易型商品 / 询盘型商品）采用不同规则。

**规则组 1**（HK、TW、VN、EU4、US、JP）：
- **交易型商品**：交易确定性（+0.3）、趋势力（+0.2）、价格力（+0.2）、服务力（+0.3）
- **询盘型商品**：价格确定性（+0.1）、定制力（+0.3）、趋势力（+0.2）、服务力（+0.4）

**规则组 2**（PK、IN、KR、MX）：
- **统一评分**：交易力（+0.3）、趋势力（+0.2）、价格力（+0.2）、服务力（+0.3）

## scoreDetails 扣分项枚举说明

`scoreDetails` 是 `query_product_score` 接口返回的 Map 结构，**值为 `true` 表示存在此项问题**，值为 `false` 或不存在表示该项正常。

> **⚠️ 本章节是 `scoreDetails` 扣分项含义与修复路径的唯一真相源。Agent 在解读 `scoreDetails` 时，必须查阅本表，禁止凭字段名望文生义或自行推断修复方案。**

### 分类说明

- **A 类**：Agent 字段层可处理项 — 对应 `actions-and-presets.md` 中的 action 枚举，可通过批量优化工具或 Sub Agent 处理
- **B 类**：需用户后台/线下操作项 — 不在 actions 枚举内，需用户自行在平台后台操作
- **C 类**：不可干预项 — 平台算法判定，无法通过优化改变

### 使用说明

1. Agent 在执行**强制动作 2.5**（解读 scoreDetails）时，**必须查阅本表**确定每个扣分项的分类和修复路径
2. 对于 **A 类**扣分项，Agent 应根据"对应 actions 字段"和"优化策略"列，自动构造优化方案并执行
3. 对于 **B 类**扣分项，Agent 应明确告知用户需要在平台后台执行的操作
4. 对于 **C 类**扣分项，Agent 仅需向用户说明该项由平台算法判定，无法通过优化改变
5. 当某个扣分项涉及**多个 actions 字段**（如 `category` 对应 `CATEGORY` + `TITLE`），表示需要联动优化，Agent 应在同一轮优化中同时处理这些字段
