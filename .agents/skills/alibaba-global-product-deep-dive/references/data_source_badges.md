# Data Source Badges Reference

## Badge Definitions

| Badge | Platform | When to Use |
|-------|----------|-------------|
| Jungle Scout | Jungle Scout | Keyword data, competitor metrics, market concentration, trends |
| Amazon | Amazon | Product listings, BSR, reviews, pricing |
| Alibaba | Alibaba | Supplier data, B2B sourcing, FOB pricing |
| Web | Web/Google | General market research, trend articles |
| Google Trends | Google Trends | Search trend data, seasonal patterns |
| TikTok Shop | TikTok Shop | TikTok trending products |
| Temu | Temu | Temu hot-selling data |

## Badge Placement Rules

1. **Section headers**: Relevant source name next to the `##` header
2. **Key Data Points table**: Source column uses external platform name (e.g. Jungle Scout, Amazon, Alibaba)
3. **Multiple sources**: Each distinct external source gets its own mention
4. **Same source block**: Mention only ONCE at the beginning
5. **Internal tools**: Do NOT expose internal tool names — always map to the external platform the data comes from
