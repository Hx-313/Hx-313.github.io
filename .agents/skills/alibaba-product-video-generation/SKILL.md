# 视频生成路由技能

本 Skill 统一调度视频生成相关能力，执行目标是根据用户需求自动路由到对应的子 Skill

## 能力边界

本技能**仅覆盖 2 种视频生成能力**：商品场景视频、多分镜视频生成。

**以下场景均不属于本视频生成能力范围：**

- ❌ **视频后期类**：视频剪辑 / 拼接 / 裁剪 / 后期处理
- ❌ **音频字幕类**：替换音频 / 加字幕 / 视频翻译 / 视频配音
- ❌ **图像生成类**：生图 / 修图 / 图片处理（去背景、换色、加 Logo、模特图等）

**意图识别注意事项：**

- 用户附带视频要求"分析/点评" → 属于视频审阅意图，不执行本技能。
- 用户要求"写视频脚本/文案/分镜文字" → 属于文案生成意图，不执行本技能。
- 用户意图模糊（既像生图又像生视频）→ 必须追问确认，禁止默认假设。

## 子能力路由

### 🎬 1. 商品场景视频 (scene_video_generate_skill)

**文件路径**：references/scene_video_generate_skill.md
**触发条件**（必须全部满足）：

- 用户明确要求生成商品/产品的场景视频
- 提供了一张图片输入 (非多张图片)
- 未提到"多分镜"
- 若提到时长，则 ≤ 8 秒

**示例请求**：

- "生成这个透明玻璃杯的视频，阳光透过透明杯身和金黄色液体在桌面上投射出焦散光影，光影缓慢自然移动，镜头进行极小范围的平移"（附带商品图片）
- "给这个产品做一个场景展示视频"（附带商品图片）
- "生成一个 6 秒的商品视频"（附带商品图片）

### 🎞️ 2. 多分镜视频生成 (command_video_generate_skill) — 默认路由

**文件路径**：references/command_video_generate_skill.md

**触发条件**：除明确命中「商品场景视频」之外的所有视频生成场景，均走此能力（无论是否提供图片输入）。典型包括：

- 文生视频（无图片输入）
- 用户提到"多分镜"
- 时长 > 8 秒

**示例请求**：

- "参考这张图，生成一个多分镜的视频"
- "帮我制作一个视频，分镜1:xxx, 分镜2:xxx..."
- "生成一个包含 4 个分镜的创意宣传视频"
- "根据这段文字生成一个视频"（文生视频）

## 路由判定逻辑

```
IF 用户明确要求"商品/产品场景视频"
   AND 提供了图片输入
   AND 未提及"多分镜"
   AND （未提及时长 OR 时长 ≤ 8 秒）
THEN → references/scene_video_generate_skill.md

ELSE → references/command_video_generate_skill.md（默认路由）
```

## 执行流程

路由确定后：

1. 读取对应子 skill 文档
2. 严格按照对应子 skill 的指引执行视频生成流程
3. **严格遵守子 skill 中定义的输出格式执行视频生成**

> 本 skill 仅负责路由决策。所有后续执行流程（输入校验、参数提取、命令调用、结果轮询、错误处理、输出格式等）均以路由到的子 skill 文档为准。

## 未命中处理

当用户请求无法明确判断属于本技能覆盖的视频生成场景时（包括越界请求与意图模糊请求），返回以下引导文案：

2. **多分镜视频生成** - 生成多分镜创意视频（适用于广告、宣传、产品介绍等）

请描述您的具体需求，例如：

- "帮我生成一个 6 秒的商品场景视频"
- "帮我做一个多分镜的商品视频"
