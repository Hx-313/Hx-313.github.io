# 定招主题 — 错误场景与兜底策略

本文列举所有已知的异常场景和对应处置方式。Agent 在工具调用失败或返回异常时**必须按本文处置**，不可自行发明兜底方案。

---

## E-01 查询返回空（无匹配主题）

**判定条件**：`success=true` × `dataList=[]`（空数组）

**含义**：条件合法但无匹配结果

**应对**：
- 按 §9.5 空结果模板输出条件说明
- 引导放宽条件（去掉 tab / 国家 / 换上级类目）
- **禁止**：自动缩短关键词重搜 / 退化类目 / 切业务线 / 输出"建议行动"列表

---

## E-02 类目无权限

**判定条件**：`query_user_valid_category` 返回的 Map 中**不包含**用户指定的 cateId（或中文名无法匹配到任何 entry）

**含义**：商家未开通该类目经营权限

**应对**：
- **不调 `farseer_topic_search`**
- 告知用户该类目不在经营范围
- 展示用户拥有权限的一级类目列表（`level=1` 的 name 列表）
- 引导换一个有权限的类目查询

**话术示例**：
> 你的账号暂无「{类目名}」的经营权限，无法查询该类目下的定招主题。你当前可查询的一级类目有：{类目列表}。请选择一个类目重新查询。

---

## E-03 类目查询失败

**判定条件**：`query_user_valid_category` 调用失败（网络异常 / MCP 通道故障）

**应对**：
- 自动重试一次
- 仍失败 → 报错终止，告知用户"类目权限查询失败，请稍后重试"
- **不可跳过鉴权直接查主题**

---

## E-04 tab 词不在枚举

**判定条件**：用户指定的 tab / strategyTag 不在 §5.1 枚举中

**应对**：
- **不要把未知值硬传进 `strategyTagList`**
- 展示可用 tab 列表让用户选择（**仅展示引导中的三种**：全网热卖 / 站内热卖 / 站内稀缺）
- 如果用户表述模糊（如"热门"），参照 §5.3 热卖路由规则判定

**话术示例**：
> 「{用户表述}」不在当前支持的筛选标签中。你可以选择：全网热卖 / 站内热卖 / 站内稀缺。

> ⚠️ **注意**：虽然引导中仅展示三种标签，但如果用户**明确要求**"海外现货"或"半托管"，仍正常执行查询（只是不主动引导）。

---

## E-05 返回 success=false（接口报错）

**判定条件**：`success=false`

**含义**：后端拒绝请求，通常因参数不合法或系统异常

**应对**：
- 原文展示 `errorMessage`（不解读、不编造）
- 检查参数是否违反 §3.2 / §5 约束（常见：`businessType` 与 tagCode 不匹配）
- 可修正 → 修正后重试一次
- 不可修正 → 报错终止

---

## E-06 主题命中但无候选品

**判定条件**：`success=true` × `dataList` 非空 × 某条主题 `productCount=0`

**含义**：主题存在，但当前账号下无可发候选品

**应对**：
- 输出表格时**仍展示该主题**（`topicId`/`title` 存在就不删行）
- 在该行的相关列旁加简短备注"当前账号无候选品"，或在表格下方追加一行说明
- 建议用户联系类目运营或选其他主题

---

## E-07 关键词与 topicIds 冲突

**判定条件**：用户同时给出关键词与 topicId，或工具被同时传了 `title` + `topicIds` 而返空

**含义**：`title` 与 `topicIds` 同传是交集查询（SQL `topicId IN [...] AND title LIKE %xxx%`），很容易空集

**应对（调工具前应先识别）**：
- **优先 `topicIds`**（更精确）→ 把 `title` 置 `""`
- 或反问澄清"你是只看 topic X，还是搜关键词 xxx 全部？"
- 不要"二者都传试试看"

---

## E-08 非数字 topicId

**判定条件**：用户给的 topicId 不是纯数字（如 "abc123" / "TOPIC_001" / "12345-x"）

**含义**：`topicIds` 字段是 `string[]`，元素必须是纯数字字符串，非数字必报 schema 错或被静默丢弃

**应对**：
- **拒绝调用**（不要硬转 `topicIds=["abc123"]`，也不要从字符串里提取数字硬转 `["123"]`）
- 反问用户"主题 ID 必须是数字，例如 12345，请确认 ID"
- 在用户给出有效数字 ID 前**不调工具**

---

## E-09 互斥参数冲突

**判定条件**：用户同时表达"查看已发品主题"（`hasDirectProduct=true` 语义）与"排除已发品主题"（`filterHasDirectProductTopic=true` 语义）

**含义**：这两个参数语义相反，后端 SQL 必返空集

**应对**：
- **拒绝调用**（不要自行决定用哪个）
- 反问"你想看**已发品**的主题，还是**排除已发品**的主题？"
- 用户明确选择后再调工具

---

## E-10 业务线与筛选词错配

**判定条件**：筛选词（tab / topicTag）与默认业务线绑定冲突。例：
- 交易品语境下用户提"世界杯"（世界杯专题是商机品专用 topicTag）
- 商机品语境下用户提"全网热卖"（全网热卖是交易品专用）

**含义**：tagCode / 字段与 `businessType` 不匹配，后端必返空

**应对**：
- 识别业务线绑定冲突，**反问** "「XX」属于「YY」业务线，是否切到「YY」定招？"（用中文展示）
- 得到用户确认后，切 `businessType` 并按 §5.4 重取 tagCode 调工具
- **不要默默切业务线**不告知用户

---

## E-11 单次返回过多（数据上限）

**判定条件**：`success=true` × `dataList.length > 10`

**应对**：
- 渲染前 10 条，这 10 条必须**逐条完整输出**，不可省略任何一行
- 在表格上方加提示行："返回结果较多，只展示前 10 条，建议收窄筛选条件（如加 tab / 类目 / 国家）以获取更精准的结果"
- 超出 10 条的部分不渲染
- **⛔ 禁止透露具体总数（铁律）**：如"共 XX 条""超过 10 条"等，仅提示"结果较多"。**任何情况下都不可向用户展示 totalItem / total 等总数字段**。

---

## E-12 网络 / MCP 调用错误

**判定条件**：工具调用失败（网络超时 / MCP 通道异常 / HSF 连接失败等非业务性错误）

**含义**：底层通信故障，非参数问题

**应对**：
- **自动重试一次**（仅限网络 / MCP 层面错误，业务错误如 `success=false` 不重试）
- 若重试仍失败，**向用户报告错误并终止流程**
- 不要无限重试，最多一次

**话术示例**：
> 调用工具时遇到网络错误，已自动重试但仍然失败。请稍后再试，或检查网络连接。

---

## E-13 其他无法处理的异常

**判定条件**：不属于以上任何已知错误类型的异常情况

**应对**：
- **立即终止当前流程**
- 向用户报告异常信息（原文输出，不解读）
- 询问用户处理意见（是否重试 / 换条件 / 放弃等）

**话术示例**：
> 执行过程中遇到异常：[异常信息]。已终止当前查询，你可以选择重新查询或调整查询条件。

---

## E-14 发草稿失败

**判定条件**：`listing_product_draft_by_topic` 返回 `success=false`

**含义**：草稿请求提交失败

**应对**：
- 在草稿结果表格中标记为 ❌ **存草稿失败**
- 按 [`topic-listing.md`](topic-listing.md) §9.3 对失败原因进行分类（业务错误 / 系统错误）
- 批量场景下，单个失败**不影响其他 topicId 继续执行**
- **草稿失败的品不进入发布阶段**
- 全部失败时不进入发布阶段，展示"全部失败"引导文案

**常见 errorCode**：

| errorCode | 分类 | 建议 |
|---|---|---|
| `DRAFT_SUBMIT_ERROR` | 系统错误 | 稍后重试 |
| `DRAFT_BUSINESS_ERROR` | 业务错误 | 检查主题状态 |
| 其他 | 默认系统错误 | 引导联系运营 |

---

## E-15 发品无前置查询

**判定条件**：用户表达发品意图，但本会话**未执行过** `farseer_topic_search` 或查询无结果

**含义**：当前阶段业务规则要求"先查后发"，本 Skill 接收到发品意图后发现前置条件不满足

**应对**：
- **暂不调用任何发品工具**
- 如果用户提供了 topicId → **先用 `topicIds` 调 `farseer_topic_search` 查出该主题信息展示给用户**，然后引导确认发品
- 如果用户未提供 topicId → 引导用户进入查询流程

**话术示例**：
> 发品前需要先确认目标主题。告诉我你想查的类目或关键词，我帮你找到主题后再发品。

---

## E-16 发品 topicId 不在查询结果中

**判定条件**：用户指定的 topicId 不存在于本会话 `farseer_topic_search` 返回的 dataList 中

**含义**：无法确认该主题是否存在/有效，需要先通过查询验证

**应对**：
- **不直接调用发品工具**
- 反问用户："topicId {X} 不在刚才的查询结果中，需要我先帮你查一下这个主题的信息吗？"
- 用户确认 → 先用 `topicIds=["{X}"]` 调 `farseer_topic_search` 查验 → 有结果后再走发品流程
- 用户取消 → 终止

---

## E-17 能力边界外操作

**判定条件**：用户 query 触发了定招/征品意图，但请求的操作**不属于当前已实现的"查询主题"和"发品"两种能力**

**典型场景**：
- "把我这个商品转换为行业定向征品"
- "帮我优化定招品的标题/图片/详情"
- "帮我删除定招品"
- "帮我修改定招品价格"
- "帮我查看定招品的流量数据"

**应对**：
- **不调用任何工具**
- 友好告知当前能力边界，引导到已支持的能力

**话术示例**：
> 当前定招 Skill 仅支持**主题查询**和**发品**操作。你提到的「{用户请求}」能力正在开发中，敬请期待后续版本。如需查询定招主题或发品，可以告诉我关键词或类目。

---

## E-18 发布上线失败

**判定条件**：`publish_product_draft_online` 返回 `success=false`

**含义**：发布请求提交失败

**应对**：
- 在发布结果表格中标记为 ❌ **发布失败**
- 按 [`topic-listing.md`](topic-listing.md) §9.3 对失败原因进行分类（业务错误 / 系统错误）
- 批量场景下，单个失败**不影响其他品继续执行**
- 全部失败时展示"全部失败"引导文案

**常见 errorCode**：

| errorCode | 分类 | 建议 |
|---|---|---|
| `PUBLISH_ERROR` | 默认系统错误 | 稍后重试 |
| `PUBLISH_BUSINESS_ERROR` | 业务错误 | 检查商品信息 |
| `TIMEOUT` | 系统错误 | 稍后重试 |
| 其他 | 默认系统错误 | 引导联系运营 |

---

## E-19 草稿成功但 categoryId/draftProductId 缺失

**判定条件**：`listing_product_draft_by_topic` 返回 `success=true` 但 `categoryId` 或 `draftProductId` 为 null / 缺失

**含义**：草稿创建成功但后续发布所需的参数不完整

**应对**：
- 草稿结果表格正常展示为 📝 **存草稿成功**，操作列提供编辑链接（如 draftProductId 缺失则不提供链接）
- **不进入发布阶段**（缺少必要参数）
- 在草稿结果表格下方追加说明："草稿已保存，但无法自动发布上线。请前往卖家后台手动发布。"

## 通用原则

| 原则 | 含义 |
|---|---|
| **网络错误自动重试一次** | 网络 / MCP 调用错误自动重试一次，仍失败则报告用户并终止 |
| **业务错误不静默重试** | `success=false` / 限流 / 类目无权限 都不重试，先告知用户根因 |
| **不发明数据** | tagCode / topicId / title / URL / categoryId / productId / draftProductId 都不允许用训练数据或历史会话补 |
| **反问优于猜测** | 边界场景宁可多问一次也不要猜错调工具 |
| **保留筛选条件透明** | 告知用户"我用了什么条件"（用中文展示），而不是"无数据"一句话甩回去 |
| **异常即终止** | 无法处理的异常立即终止流程，询问用户处理意见 |
| **模糊型退化** | 模糊型 Query 走类目筛选返空时，自动退化为主题名称搜索，不终止流程 |
| **搜索完即停止** | 明确搜索/模糊型/推荐各场景搜索流程结束后立即停止，禁止自行发散 |
| **空结果简洁报空** | 空结果仅告知条件 + 引导放宽，禁止输出"建议行动"等超职责内容 |
| **禁止展示内部码** | 所有面向用户的输出中，tagCode / categoryId 等内部码必须翻译为中文名称 |
| **禁止展示总数** | 任何情况下都不展示主题总数/结果总数，仅渲染最多 10 条数据 |
| **发品必先查** | 无前置查询不可直接发品，需先查出主题信息 |
| **批量最大 5 并发** | 每批最多 5 个并行调用（草稿或发布均适用），一批完成后立即渲染结果表格，再处理下一批 |
| **能力边界友好拒绝** | 超出当前能力范围的定招操作，友好告知并引导到已支持的能力 |
| **失败品允许重试** | 批量发品中失败的品，用户可通过序号单独重试，无需重新查询 |
| **草稿失败不进发布** | 草稿失败的品不进入发布阶段，仅在草稿结果表格中标记 |
| **发布成功无超链接** | 发布结果表格中所有行均为纯文本，不添加任何超链接 |
