## Workctl 服务配置

### 服务信息

|     |   |
|--------|----|
| **服务名称：** |  国际站知识查询 |
| **调用工具：** |  `workctl` |
| **命令路径：** |  `icbu.cco.icbu-faq-knowledge-chunk` |
| **命令：** |  `workctl icbu cco icbu-faq-knowledge-chunk` |

### 调用参数
```json
{
  "query": "什么是信用保障订单"
}
```

### 调用方法
```bash
workctl icbu cco icbu-faq-knowledge-chunk \
  --query "什么是信用保障订单" \
  --format json
```

## 错误处理与降级交付

当 `icbu-faq-knowledge-chunk` 调用失败、返回为空或权限受限时，**禁止只说"无法完成"**，必须按以下降级路径输出可用产物：

- **接口调用失败：** 自动重试一次（不同时刻可能恢复）。仍失败时：
  - 告知用户具体错误（错误码 + 接口名）。
  - 基于自身知识就 query 主题给出**通用回答框架**（标注"⚠️ 知识库接口不可用，以下为通用说明，建议刷新后从知识库验证"）。
  - 严禁用"无法回答"或"请稍后再试"作为最终交付。

- **接口返回为空（query 在知识库中无匹配 QA）：**
  - 不要直接抛"未找到知识"。先做一次 query 同义改写（如把"信保订单"改写为"信用保障订单"、"信任订单"等），再调用一次。
  - 仍为空时，明确告知"该问题不在国际站官方 FAQ 知识库中"，并主动给出 2-3 个相近主题的官方文档链接，让用户自行选择。

- **能力边界前置告知：** 当用户问题涉及实时操作（如"帮我修改运费模板"）、跨平台能力（如 Lazada / 速卖通）或需要订单/账号上下文时，本 skill 不应承担解答职责：
  - 立即告知"本 skill 只支持国际站官方 FAQ 知识库的检索回答"。
  - 引导用户使用对应的操作类 skill，禁止编造 FAQ 内容。

- **回答完整性兜底：** 凡基于 `icbu-faq-knowledge-chunk` 返回内容回答时，必须保留至少 1 条「相关 QA 引用」（Q + A 摘要 + 出处链接），便于用户溯源；接口未返回出处字段时，至少标注"来源：国际站官方 FAQ 知识库"，禁止把回答伪装为模型自身知识。

- **推理中止与熔断：**
  - **搜索尝试限制：** 若连续 3 次通过 `icbu-faq-knowledge-chunk` 或同类搜索工具（如同义词改写后）均未获取到有效知识片断，必须立即中止自主推理，不得继续尝试其他搜索或扫描本地文件。
  - **无果处理：** 中止后进入 fallback 引导：告知用户"已深度检索国际站官方知识库，暂未发现与『{query}』直接相关的官方说明"，并提供官方客服链接或建议用户换个关键词提问。
  - **禁止事项：** 严禁在知识库无果时尝试 `ls`、`list`、`grep` 等文件系统工具来寻找云端知识库配置或文档。
