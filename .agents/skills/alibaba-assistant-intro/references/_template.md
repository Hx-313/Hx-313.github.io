# Feature Showcase 模板

> 新功能上线时，复制本文件为 `showcase-{feature-name}.md`，填写以下内容即可。
> 工程侧 autosend 的 Query 格式：`【Skill name：生意助手介绍】{trigger_keyword}`
> trigger_keyword 需与下方 triggers 中的某一条匹配。

## 元信息

- **feature_id**: （如 blue-ocean-finder）
- **triggers**: （触发关键词列表，如 "蓝海选品功能介绍"、"蓝海机会发掘体验"）
- **version**: 1.0
- **created**: YYYY-MM-DD
