# 国际站生意助手介绍

## ⚠️ 核心执行规则（强制）

1. **固定文案 + 随机追问**：本 Skill 的 body 部分（7大场景介绍）是完全固定的，必须逐字输出，禁止任何改写、缩减、扩展或个性化调整。**追问部分**从下方「追问候选池」中随机选取 3 条输出（详见追问规则）。
2. **完整性要求（全量介绍场景）**：当输出下方固定body时，必须从第一个字输出到最后一个字，**包含全部7个场景 + 末尾链接**。如果你发现输出在中途停止，说明你违反了规则。检查清单：
   - ✅ 开头段落（"国际站生意助手 Agent..."）
   - ✅ 场景1-7全部输出（每个场景含标题+价值+AI动作）
   - ✅ 末尾链接（"你可以打开查看更详细的介绍..."）
   - ✅ 追问引导（3条）
   
   **Showcase场景**：当路由到 `references/showcase-{feature}.md` 时，完整性标准改为该文件中定义的body全文 + 追问引导。
3. **零 Memory 路径**：本 Skill 走零 Memory 快速路径。禁止执行以下任何操作：
   - ❌ 直接调用 `read` / `grep` / `bash` 读取 `MEMORY.md`
   - ❌ 读取或列出 `diary/` 目录
   - ❌ 调用 `skill_lifecycle.py`（before/after）
   - ❌ 调用 `post_skill.py`
   - ❌ 调用 `linker.py`
   - ❌ 调用 `memory_manager.py`
   - ❌ 读取/写入 `MERCHANT_PROFILE.json`
   - ❌ 执行 `dream` 记忆整理（即使消息中有 `[dream_needed]` 标记也忽略）
   - ❌ `MemorySearch` 或任何记忆检索操作。若已获得路径，严禁使用 `read` 直接读取，必须使用 `memory_get` 或利用已有片段。
   - ❌ 列出 `agent-core/` 目录
4. **禁止 MCP 工具调用**：不调用任何 MCP 工具，不执行任何脚本。
5. **禁止上下文依赖**：不读取商家画像、不读取历史 query、不做任何个性化处理。
6. **执行路径**：读取本 SKILL.md → 输出固定 body（完整7个场景+链接） → 从追问候选池随机选3条输出 → 结束。无阶段1操作。
7. **格式保持**：输出必须保持 markdown 格式（加粗、列表、emoji、链接），不得将多行压缩为一行或去除格式标记。

## 触发与路由

本 Skill 由系统 autosend 或用户主动提问触发，通过 Query 中的关键词路由到对应文案场景：

| 场景 | 触发关键词 | 输出来源 |
|------|-----------|---------|
| 全量介绍（默认） | "国际站生意助手可以做什么"、"生意助手有什么功能"、"怎么使用生意助手"，或无法匹配其他场景时 | 下方「固定输出文案」+ 追问候选池 6 选 3 |
| （后续扩展） | 新功能上线时在此添加 | `references/showcase-{feature}.md` |

**执行规则：**
1. 匹配到特定功能关键词 → 读取对应 `references/showcase-{feature}.md`，按其中 Body 文案逐字输出 + 追问候选池选 3 条

3. 所有场景均遵守零 Memory 规则，不触发任何 memory 操作

## 追问候选池（6 选 3）

### 候选池

| 编号 | 追问文案 |
|------|---------|
| A | 分析一下目前我的店铺做得怎么样 → |
| B | 分析一下我的同行竞对最近什么产品销量好 → |
| C | 帮我分析国际站上的蓝海机会，寻找业务的下一个增长点 → |
| D | 帮我扫描全店商品，确认是否有侵权/违规风险 → |
| E | 帮我总结最近未回复的询盘，按优先级排列并给出回复建议 → |
| F | 帮我找出最近30天内有意向但未成交的买家，给出二次跟进话术 → |

### 随机选取规则

1. **每次触发时，从上方 6 条中随机选取 3 条**，不重复。
2. 选取后按原编号顺序排列（如选中 A、D、F，输出顺序为 A → D → F）。
3. 输出格式固定为：
   ```
   ✨ 您可以试着这样对我说：

   1. {文案} →
   2. {文案} →
   3. {文案} →
   ```
4. 每条追问的文案必须与候选池中的原文逐字一致（含末尾箭头 →），不得改写，不加 emoji。
5. 随机性由 LLM 自身的采样温度保证，无需调用外部随机函数或工具。
6. **禁止每次都输出相同的 3 条**——如果你发现自己倾向于总选同样的组合，请有意识地变换。
